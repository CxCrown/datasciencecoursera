# Getting and Cleaning Data Course Project 
## Project Overview
This project was done as part of the Data Science: Foundations using R Specialization.
The purpose is to demonstrate the ability to collect, work with, and clean a data set.

### Goal of the project
1. Creating a tidy data set
2. Provide a script for performing the analysis. The script should be called run_analysis.R
3. Providing a link to a GitHub repository containing a script for performing the analysis
4. Provide a code book that describes the variables in the data set, the data, and all the  transformations or work that you performed to create the data. The code book should be called CodeBook.md. 
5. Provide a README that explains how all of the scripts work and how they are connected. This README should be called README.md.
 
 
### Instructions for the project
You should create one R script called run_analysis.R that does the following. 

1. Merges the training and the test sets to create one data set.

2. Extracts only the measurements on the mean and standard deviation for each measurement. 

3. Uses descriptive activity names to name the activities in the data set

4. Appropriately labels the data set with descriptive variable names. 

5. From the data set in step 4, creates a second, independent tidy data set with the average of each variable for each activity and each subject.

### Repository Contents for this project
The GitHub Repository will contain the following contents: 

* run_analysis.R: R script containing the all the steps for downloading, cleaning, merging and transformation of the data.

* tidy_data_mean.txt: text file containing the final tidy data set with the average of each selected measurement variable for each subject and activity.

* CodeBook.md: contains the documentation describing the variables, measurements, and transformations applied to the data set.
